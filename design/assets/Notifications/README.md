The macOS notification badges, 128px PNG, one per notification kind, each in the light-theme hue of what it means: `round.png` (a round is pending, `loop` clock), `ask.png` (an agent asks or stopped, `me` question), `held.png` (a daily cap held a round, `late` pause), `blocked.png` (a first round is blocked, `err` stop). Use them only in notifications. The files live in `internal/client/menubar/macos/img/`.
