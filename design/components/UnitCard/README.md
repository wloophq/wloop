# UnitCard

*Proposed.* The generic face of any unit in an entry's inspector, read from `card.Card`.

SourceChip and link out, title, the plugin's state word as a pill, waits-on strip, age and waiter, the why sentence, the last human move, and the signals colored by tone (`good` `loop-text`, `warn` `late`, `bad` `err`, `info` `me-text`, `neutral` `muted`). Stale when its plugin is off.

## Consumer provides
The card snapshot. Nothing provider-specific: the plugin's richer page opens from "Open in".
