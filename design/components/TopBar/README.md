# TopBar

The cockpit's single header: brand mark, filter box, sync line, notice.

- `mark`: product name in `brand` mono, after a `▍` in `me`.
- `search`: the filter (`/` focuses it); qualifiers like `repo:`, `wait:me`.
- `sync`: freshness in `code` `muted`; `late` when slow or paused.
- `notice`: the last outcome, right-aligned, `muted` (or `err`). One line, ellipsis.

The pause control sits at the far right as a Button.
