# Rail

The left column of views with counts, in groups headed by an `overline`.

Each item is a link with a `label` and a `count` (`code`, `muted`). The current view is `sel` with a `strip-card` bar in `me` and 600 weight; Stalled's count is `late` and bold. Below `breakpoint-narrow` the rail becomes a wrapped tab row with the bar on the bottom.

## Consumer provides
Views from the daemon's catalog, already ordered; the group headings (see Information architecture for the proposed grouping by intent).

## Do / don't
- Don't add per-person lists here; "waiting on" is a toolbar facet.
