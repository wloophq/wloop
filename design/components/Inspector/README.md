# Inspector

*Proposed.* The entry's detail as OmniFocus's inspector: fields instead of a wall of buttons.

Head (glyph, title, star), the state as one segmented control plus Done and Trash, the field list (Project, Contexts, Area, Deadline, Snooze, Waiting on; an empty field shows an `add` link), Items, Sources as UnitCards, then the action slots.

## Action slots
Placed from each action's catalog fields, never its id: the recommended one `primary`; verb `delegate` in the guidance block; verb `approve` in a question or draft; the rest by group. An action whose manifest comes from the user's profile carries the `profile` flag (the "Security pass" button is a profile intent).

## Consumer provides
The entry, its items, its cards, and the action states the daemon offers for it.
