# BoardCard

The board layout's unit: the row grammar stacked in a card.

`panel` fill, `rule` border, `radius-md`, `strip-card` left edge in the waiter's mark color. Title, meta, tags, age. Selected adds the `me` tint and inset bar; `.mine` uses `mine-bg`.

## Consumer provides
The same unit data as PullRequestRow. Cards sit in a lane (`lane-head` with an `overline` title and count).
