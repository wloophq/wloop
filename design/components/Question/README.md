# Question

What an agent round asks you when it stops, with its options and a free answer.

`bg` inset with a `me` strip (a question always waits on you). `overline` label, the summary in `row-title`, the verdict in `muted`, the options as Buttons with the recommended one `primary` and marked, then a free answer and Continue and Dismiss.

## Consumer provides
The question, its options from the daemon (recommended first), the agent's full text (collapsed under a disclosure).

## Do / don't
- Do set the agent's text in `body` sans.
