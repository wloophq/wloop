## What the comment says

Say what the pull request waits for from them and since when, and ask for
one concrete next step: review the latest push, answer a question in a
thread, merge, or say whether the change is still wanted. Link what the step
is about: the thread or the commit when there is one, else the pull request.

## Tone and form

- Tone: neutral and friendly, never pressing. No pressure, blame or urgency
  language: no "ASAP", "blocking us", "still waiting", "as I said".
- Length: one to three sentences.
- Language: the one the pull request's conversation uses; English when it
  has none.
- Sign-off: none.
- Write as the user: no mention of automation or agents.

## When to hold back

Post nothing when someone already asked them for the same thing in the last
working day.
