# Workflows

Each workflow is a directory here holding `workflow.toml`; plain files such as this one are ignored. The bundled ones start review and address rounds (`review-*`, `address`), nudge whoever someone else's pull request silent for 30 days waits on (`nudge-silent-30d`, which waits for you), propose Slack nudges, closures and owner questions in the Outbox (`slack-*`), close finished or quiet agent sessions (`session-*`), remove or unregister finished, temporary, duplicate and idle workspaces (`workspace-*`; the removals ship in observe mode, and `workspace-idle-no-pr` waits for you), keep the turn records consistent (`hygiene-*`), and close an entry you captured once every unit attached to it has ended (`entry-results-ended`). A profile overrides a bundled workflow with a directory of the same name; `workflows.<name>` in the config sets its mode, turns it off or changes its approval.
